# Glossary (10–12 terms)

| Concept | Meaning |
|---------|---------|
| DEG | Differentially expressed gene |
| TMM | Trimmed Mean of M-values (RNA-seq library-size scaling) |
| log2FC | Magnitude and direction of expression change (log2 fold change) |
| FDR | Expected proportion of false discoveries among rejected tests (BH) |
| SMOTE | Synthetic minority oversampling; **train set only** |
| TP | Correctly identified positive |
| FP | Incorrectly identified positive (false alarm) |
| FN | Missed positive |
| Sensitivity | TP / (TP + FN) |
| Specificity | TN / (TN + FP) |
| ROC | Sensitivity vs false-positive rate across thresholds |
| AUC | Area under the ROC; overall discrimination |
